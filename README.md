## Front end web development project

A multi-page responsive web application developed as part of the Software Engineering program at Western Governors University. This project highlights modern HTML and CSS structuring, clean layout design, and targeted city data presentation.

## Features

* **Multi-Page Layout:** Features dedicated pages for multiple locations ([Spokane](spokane.html), [Seattle](seattle.html), and [Olympia](olympia.html)) alongside a main [Home](index.html) and [Contact](contact.html) page.
* **Structured Data Presentation:** Clear integration of demographic and income statistics across target regions.
* **Responsive Styling:** Custom CSS formatting and layout management to ensure consistent user experience across viewports.

## Built With

* **HTML5** (83.4%)
* **CSS3** (16.6%)
* **Git & GitHub** for version control
